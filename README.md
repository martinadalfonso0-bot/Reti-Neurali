# Animal Image Classification with CNNs

Deep Learning project for **multiclass image classification** across three categories: **brown bears, carps and dogs**.

The project compares two approaches:

* a **Convolutional Neural Network (CNN)** built from scratch;
* **Transfer Learning with InceptionV3**.

## Technologies

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Scikit-learn

## Workflow

* Image preprocessing
* Data augmentation
* CNN training
* Transfer Learning
* Model evaluation using Accuracy, Precision, Recall, F1-score and Confusion Matrix

## Results

The custom CNN achieved approximately **88% validation accuracy**, outperforming the tested InceptionV3 model.
